## 🌟 三条配对路，总有一条通

```
① 蓝牙配对（推荐）── 不碰 Wi-Fi，APP 点一下，电脑批准，完事
② 局域网扫码      ── 同网络秒配
③ 热点扫码        ── 没网时电脑开热点（你的 Wi-Fi 不会断！）
```

**蓝牙配对**是 Tandem 的魔法时刻 (◕‿◕)：

- 手机**不需要连任何网络**——蓝牙发现电脑、递交配对请求
- 电脑端 `/pair` 页面弹出「配对请求 → 批准」——你在场就是信任锚
- 批准后手机拿到**永久设备凭证**，存好就完事
- 凭证像 adb 的指纹信任：换网络、重启、断线重连都免扫码；电脑上可随时吊销

> 蓝牙只递「敲门砖」不递钥匙——嗅探到配对请求也没用，批准权在电脑前坐着的你手里 🔐

## 📦 安装

**Windows 零配置**：下载 `tandem.exe`（[Releases](../../releases)）→ 双击 → 住进系统托盘。
开机自启：`tandem.exe --autostart on`

**任意平台**（Python 3.10+）：

```bash
pip install tandem-link
tandem
```

源码运行：

```bash
git clone https://github.com/wumai2580/tandem && cd tandem
pip install -e .
cd web && npm install && npm run build && cd ..
tandem
```

> Windows 首次启动弹防火墙提示 → 点**允许**，不然手机找不到中枢哦 (˶˃⤙˂˶)

## 🎀 日常使用

- **手机 → 电脑**：相册分享照片 → 选 *Tandem* → 嗖，文件躺在电脑收件箱里了（链接还会直接帮你在电脑浏览器打开）
- **电脑 → 手机**：文件拖进网页 / 粘贴文字 → 手机一秒收到
- **通用剪贴板**：电脑复制 → 手机点「复制到本机」，反过来也行
- **多设备**：配几台都行，全部走你自己的局域网，不经过任何云

### 安卓：原生分享菜单

装一次伴随 App（3.9MB）→ 打开 → 点「蓝牙配对」或扫码 → 从此 **Tandem 住在你的分享菜单里**。

- mDNS 自动发现局域网内的电脑
- 首次配对时自动固定中枢证书（TOFU）——**不用进系统设置装 CA**
- `ACTION_SEND` / `ACTION_SEND_MULTIPLE` 全支持

不想装 App 也有 PWA 路径：浏览器打开配对链接 → ⋮ → 安装应用。

### iOS / iPadOS：快捷指令

一分钟建个 *Tandem* 快捷指令，接收任意内容 POST 到中枢，就进 iOS 分享表单了。
手把手教程：[docs/ios-shortcut.md](docs/ios-shortcut.md)

## 🔧 原理

```
          ┌─────────────────────────────┐
          │   配对：BLE（不占 Wi-Fi）    │
          │   数据：LAN / HTTPS 直连     │
          │   兜底：Windows 热点（STA+AP）│
          └─────────────────────────────┘
手机 ──(分享菜单 / PWA / 快捷指令)──> 电脑中枢 ──> 其他设备
```

- 中枢：单个 Python 进程（FastAPI），纯局域网，无云端无账号
- 传输：HTTPS + WebSocket；大文件流式落盘，内存恒定
- 蓝牙只做发现和配对握手，数据走 IP——快，且不占手机 Wi-Fi
- 设备凭证存在两端，中枢注册表可列出/吊销每台设备

## ❓ FAQ

**安全吗？** 全部流量走局域网 HTTPS（每安装一份生成独立 CA）。配对要么扫码（二维码里有随机凭证），要么蓝牙请求+电脑端人工批准。文件永远不离开你的网络。

**不连同一个 Wi-Fi 能用吗？** 能。蓝牙配对完全不依赖 Wi-Fi；数据传输只要有 IP 通路就行（校园网、公司网、甚至电脑开的热点——开热点还不断主机现有网络）。

**需要联网吗？** 不需要外网。局域网通就够。
